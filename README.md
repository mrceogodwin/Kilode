# Kilode Premium — React Native (iOS first)

Nigerian community OS. Expo SDK 51 · TypeScript · StyleSheet only.

## Design
- Primary `#1877F2` · cards `#FFFFFF` · bg `#F6F8FB` · border `#E7ECF2`
- Header: `kilode` + LIVE pill · Search · bell · K avatar
- Dock: Home · Socials · **+** · Activity · My Space

## Run
```bash
npm install
npx expo start
# press i for iOS simulator, or scan QR with Expo Go
```
